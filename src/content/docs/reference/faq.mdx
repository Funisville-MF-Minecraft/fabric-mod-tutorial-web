# FAQ

## Do Fabric mods work on Bedrock?

No. Fabric mods are for Minecraft: Java Edition. Bedrock players need a bridge such as Geyser and, often, Floodgate to join a Java server.

## Can a server-side-only mod work without the client installing anything?

Yes. A server-only mod can change world rules, commands, and gameplay systems without requiring a client installation, as long as the mod does not depend on Java-only client rendering or custom client behavior.

## Why do I need Java 21?

A Fabric version target usually requires a compatible Java toolchain. Using the wrong version is one of the most common reasons a project fails to build or launch.
